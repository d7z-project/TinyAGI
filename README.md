# TinyAGI

研究一个长期存在的统一主体：在数字环境与通用设备中感知和行动，按需组织心智与能力，从实际结果中形成记忆和改进。

**当前处于设计阶段，尚未发布产品。** 文档描述目标架构与设计依据；已实现的库能力、已有实验结果和待实现机制分别标明。

设计围绕五项能力展开：

- **持续处理任务**：统一事件连接观察、认知、能力调用和结果。[核心与任务解耦](DESIGN.md#core-task-control)，长任务等待或中止时，主体仍可处理其他输入。
- **按需获取信息**：资源先以描述信息呈现，主体主动选择后才读取内容；记忆、证据、检索索引和推理缓存分别管理。
- **形成并维护个体**：通过[完整提示词初始化与迁移说明](DESIGN.md#initialization-migration)创建、更新人物，允许个体差异；[客户端预制能力库](DESIGN.md#prebuilt-capabilities)供主体按需选用。
- **扩展能力与学习**：复用、组合或构建工具，在沙箱中评估后按适用范围采用。主动学习属于实验性扩展，投入有上限，也可完全关闭。
- **管理与人工控制**：Web 工作台覆盖主体状态、模型服务、沙箱副本、行为配置和用户机密；机密原值通过可信专用通路处理。

工程方案采用单机核心，业务状态保存在 SQLite，原始资源保存在本地文件中；通过 go-mini MRPC 接入 Go、Rust 和 Node.js（npm）能力。具体部署及依赖见工程参考，逻辑总图只描述职责与交互。
